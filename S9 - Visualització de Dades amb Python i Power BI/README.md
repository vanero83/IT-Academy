# Visualización de datos con Python y Power BI

## Objetivos

Practicar la selección de visualizaciones adecuadas según el tipo de variables y el objetivo del análisis, interpretando los resultados con criterio analítico y evitando generar DataFrames adicionales innecesarios.

## Contenido

- Preparación y transformación de datos para su análisis.
- Creación de visualizaciones con **Pandas, Matplotlib y Seaborn**.
- Selección del tipo de gráfico según las variables y la pregunta analítica.
- Análisis de evolución, distribución, volumen de facturación y comportamiento de usuarios.
- Comparación de compras locales e internacionales.
- Análisis de variabilidad de ingresos entre productos.
- Evaluación de concentración, dependencia y oportunidades de expansión por país.
- Análisis de transacciones aceptadas y rechazadas como indicador de fricción.
- Interpretación y documentación de los resultados obtenidos.

## Archivos

Notebook de **Google Colab (`.ipynb`)** con el desarrollo de los ejercicios, cálculos, visualizaciones y conclusiones del análisis.

> **Nota:** no se realizó el Nivel 3 de la tarea, correspondiente al desarrollo de visualizaciones en **Power BI**.
