# Sprint 12 – Power BI: Análisis de datos y storytelling

**Descripción:** Desarrollo de un informe interactivo en Power BI para analizar la evolución de las ventas entre 2020 y 2024, identificar patrones, investigar variaciones y comunicar conclusiones mediante visualizaciones orientadas a preguntas de negocio.

### Contenido
- Análisis de ventas por año, país, canal y comercio.
- Creación de visualizaciones interactivas y medidas DAX.
- Investigación de la caída de ventas de 2023, identificando los principales factores.
- Análisis de tendencias, estacionalidad y comportamiento comercial.
- Incorporación de tooltips analíticos para facilitar la interpretación.

### Temas principales
Power BI · DAX · Análisis de ventas · Visualización de datos · Business Intelligence · Data Storytelling.
