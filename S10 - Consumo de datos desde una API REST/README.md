# Sprint 10 · Uso de APIs con Python

Introducción al consumo de APIs mediante Python, utilizando la librería `requests` para realizar peticiones HTTP, trabajar con respuestas en formato JSON y convertir los datos obtenidos en DataFrames de pandas.

## Contenido

- **Notebook de Google Colab (.ipynb)** con el desarrollo de los ejercicios.
- **Archivo CSV** generado a partir de los datos obtenidos mediante la API de Open Data Barcelona: `bibliotecas_barcelona_2025.csv`.

## Temas principales

- Uso de la librería `requests`.
- Peticiones HTTP mediante los métodos GET, POST, PATCH y DELETE.
- Consulta y revisión de códigos de estado HTTP.
- Trabajo con respuestas en formato JSON.
- Uso de la API de laboratorio JSONPlaceholder.
- Consulta de la API pública de MusicBrainz.
- Búsqueda de artistas y obtención de catálogos musicales mediante identificadores MBID.
- Conversión de respuestas JSON a DataFrames con pandas.
- Uso de la API de Open Data Barcelona.
- Búsqueda de datasets mediante `package_search`.
- Consulta de recursos mediante `package_show`.
- Extracción de registros mediante `datastore_search`.
- Exportación de DataFrames a archivos CSV.
