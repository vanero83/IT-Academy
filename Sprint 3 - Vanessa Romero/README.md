# Sprint 3 · Introducción a BigQuery y SQL en la Nube

Este sprint está enfocado en la introducción a **Google BigQuery** y al uso de **SQL en entornos cloud**, mediante la resolución de ejercicios prácticos de consulta y análisis de datos.

## Contenido

* **Archivo SQL:** código utilizado para resolver los ejercicios, sin resultados de ejecución.
* **Archivo PDF:** resolución completa paso a paso, con explicaciones y capturas de pantalla.
* **Archivo Excel:** archivo utilizado como parte de los ejercicios.

## Temas principales

* Google BigQuery
* Consultas SQL
* Análisis de datos en la nube
* Filtrado, agregación y manipulación de datos
