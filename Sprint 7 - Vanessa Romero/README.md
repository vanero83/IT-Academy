# Sprint 7 · Creación de funciones, estructuras de datos y bucles

Este sprint introduce los fundamentos de **Python**, trabajando la creación de funciones reutilizables, el uso de estructuras de datos y el control de flujo mediante ejercicios prácticos.

## Contenido

* **Archivo Google Colab (.ipynb):** desarrollo completo de todos los ejercicios siguiendo una estructura común:

  * Problema planteado
  * Análisis y planteamiento del ejercicio
  * Desarrollo de funciones
  * Resultado final
  * Notas sobre el ejercicio

## Temas principales

  * Sintaxis básica de Python
  * Funciones
  * Listas, diccionarios y otras estructuras de datos
  * Condicionales y bucles
  * Modularización y reutilización de código
  * Resolución estructurada de problemas
