# Sprint 4 · BigQuery Avanzado & Analytics Engineering

Este sprint está enfocado en el uso avanzado de **Google BigQuery** y conceptos de **Analytics Engineering**, trabajando con optimización, SQL analítico y estructuras de datos complejas.

## Contenido

* **Archivo SQL:** código utilizado para resolver todos los ejercicios, sin resultados de ejecución.
* **Archivo PDF:** resolución completa paso a paso, con explicaciones y capturas de pantalla.

## Temas principales

* Particionamiento y clustering de tablas
* Vistas materializadas
* CTEs y Window Functions
* Datos anidados (Nested Data)
* Optimización de consultas en BigQuery
