# **Pandas: Limpieza, análisis y enriquecimiento de datos**

## **Objetivos**
Trabajar con Pandas para preparar, limpiar, transformar y analizar datos procedentes de diferentes fuentes, aplicando criterios de calidad y coherencia antes de generar nuevas variables e indicadores.

## **Contenido**
- Limpieza y estandarización de datos con Pandas.
- Gestión de valores nulos, duplicados e inconsistencias.
- Conversión y validación de tipos de datos, fechas y variables categóricas.
- Creación de nuevas variables y agrupaciones por rangos.
- Integración de diferentes fuentes mediante merge.
- Enriquecimiento del dataset con información externa.
- Aplicación de reglas de negocio para el cálculo de incrementos salariales.
- Validación de resultados y documentación de las decisiones tomadas durante el proceso.

## **Archivos**: 
Notebooks de Google Colab (.ipynb) con el desarrollo de los ejercicios, archivos Excel con los datos procesados y resultados finales, y gráficos exportados utilizados para la visualización y análisis de la información.
