# Sprint 11 – Power BI | HeraSphere

## Descripción

En este sprint se trabaja con **Power BI Desktop** para importar, transformar y modelar datos, crear medidas DAX y desarrollar visualizaciones que faciliten el análisis y la interpretación de indicadores de negocio.

Para dar contexto al proyecto, se creó **HeraSphere**, un marketplace ficticio con nombre, logotipo e identidad visual propia, buscando que el dashboard tenga una presentación coherente y profesional.

## Objetivos y desarrollo

- **Modelado de datos:** importación, preparación y relación de las tablas para construir un modelo funcional.
- **Indicadores comerciales:** análisis de ventas anuales, medias de transacciones, empresas participantes por país y evolución mensual de ventas, incorporando objetivos de negocio.
- **Análisis de usuarios:** visualización de transacciones por cliente, conversión de divisas e identificación de usuarios que superan determinados umbrales.
- **Análisis temporal y geográfico:** estudio de las ventas mensuales de 2018 y 2019 e indicadores específicos para evaluar el rendimiento comercial en Alemania.
- **Visualización de datos:** aplicación de buenas prácticas de diseño, jerarquía visual, filtros interactivos y uso de indicadores KPI.

## Archivos

El repositorio incluye un archivo **`.pbix` de Power BI Desktop** con el modelo de datos, las medidas DAX y los dashboards desarrollados.
